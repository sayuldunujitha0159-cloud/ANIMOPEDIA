# ANIMOPEDIA

ANIMOPEDIA is a lightweight, mobile-first animal encyclopedia built with plain HTML, CSS and JavaScript. It is designed to grow into a scientifically responsible home for animal knowledge and ANI, its dedicated AI assistant.

## Included in this first website build

- Responsive landing page with ANIMOPEDIA branding
- Search across animal names, groups, habitats, regions and facts
- Group filters and sorting
- Structured animal data for 12 starter animals
- Accessible animal profile dialogs
- Honest ANI integration placeholder that does not pretend to be a working AI
- No build step or framework required; it can be hosted as a static GitHub Pages site

## Local use

Open `index.html` in a browser. The project has no install or build command.

## Direction

The website remains useful independently from ANI. The next architectural step is to move the starter data into a dedicated data module or JSON file, then add a backend/API adapter for ANI that retrieves from the same structured records without coupling the encyclopedia UI to one AI provider.
